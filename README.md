# Conductor Strip Dimension & Tolerance Inspector

Industrial workshop and quality verification tool for bare and paper-covered conductor strips (including single strips and multi-strip / bunched conductors).

## Features
- **Bare & Covered Dimension Calculations**: Width (+ve / -ve) and Thickness (+ve / -ve)
- **Standard Tolerance Reference Tables**:
  - Table 1: Width & Thickness Tolerance
  - Table 2: Paper Covering Increase in Dimension
  - Table 3: Corner Radius Specification
- **Bunched Conductor Support**: With Single Strip Paper, Overall Paper Covering, and Constant Wax Allowance ($0.02\text{ mm}$).
- **Interactive SVG Cross-Section Diagram**
- **Shop Floor Go / No-Go Caliper Verification**
- **Mobile Responsive Design** with touch scrolling and adaptive displays.
- **Automated Test Suite**: 46 verified test cases.

## Usage
- Open `index.html` in any browser, or double-click `run.bat`.
- Run tests: `npm test` or `node tests.js`.
